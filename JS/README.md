## Introduction to JavaScript  

JavaScript (JS) is a high-level, interpreted, dynamically typed programming language primarily used to create interactive and dynamic content on websites.  
It was created in 1995 by Brendan Eich at Netscape Communications and has evolved into one of the core technologies of the web alongside:  

1. HTML – For the structure of the web application  
2. CSS – For the styling of the web application  
3. JavaScript – For defining the behavior of the various sections on web application  

Today, JavaScript is standardized under ECMAScript (ES) by ECMA International.  


### JavaScript runs in:  

1. Web browsers (Chrome, Firefox, Edge)  
2. Servers using Node.js  
3. Mobile & desktop apps  

## Why Do We Use JavaScript?  

JavaScript is essential in modern web development because it enables:  

### Dynamic Content  

1. Updating content without reloading the page  
2. Showing/hiding elements  
3. Form validation  

### User Interaction  

1. Button clicks  
2. Keyboard input  
3. Mouse events  
4. Form submission handling  

### Client-Side Validation  

1. Prevent invalid data submission  
2. Improve performance by reducing server requests  

### Backend Development  

Using Node.js, JavaScript can run on servers.  

1.  Build APIs  
2.  Handle databases  
3.  Create full-stack applications  

### Cross-Platform Development  

JavaScript is used in:  

1. Web applications  
2. Mobile apps (React Native)  
3. Desktop apps (Electron)  
4. Game development  
5. IoT systems
