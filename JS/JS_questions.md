# Questions for JavaScript programming practice and learning its basics:  

1. Find sum, difference and product of two numbers.  
2. Find area of a sphere using function.  
3. Find largest number among three numbers.  
4. Display multiplication table of 5 using while loop.  
5. Display factorial of given number using for loop.  
6. Find length of a string and reverse the given string.  
7. Display current date.  
8. Validate username and password.  
9. Validate an email address and phone number.  
10. Write JavaScript program that takes distance as input in meter and convert meters into kilometers using function.  
11. Write JavaScript program that takes temperature as input in Celsius and convert it into Fahrenheit using function.  
12. Write JavaScript program that reads 5 random numbers from the user and displays them using an array.  
13. Write JavaScript program to make simple calculator.
