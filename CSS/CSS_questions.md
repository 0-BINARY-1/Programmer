# Basic questions to learn CSS

1. Create a web page showing all heading tags using font attributes in inline CSS.
2. Create a web page with an appropriate image towards the left-hand side of the page and a couple of paragraphs about an image on right hand side using Embedded CSS.
3. Create a webpage describing family in a paragraph and list all family members in an ordered list using external CSS.
4. Create a CSS class called "abc" that sets the background color of a <div> element to yellow and the text color to black.
5. Create a webpage designing a newspaper page including an image on left side and two column contents on it.
