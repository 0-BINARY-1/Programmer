# Basic things about CSS

## Introduction to CSS

CSS (Cascading Style Sheets) is a stylesheet language used to control the presentation and layout of HTML documents.  
While HTML defines the structure of a webpage, CSS defines:

1. Colors
2. Fonts
3. Spacing
4. Layout
5. Animations
6. Responsiveness

Example:
```CSS
<p class="text">Hello World</p>
.text {
  color: blue;
  font-size: 20px;
  font-weight: bold;
}
```

**CSS works by selecting HTML elements and applying styles to them.**

## Objectives of Learning CSS

After completing this CSS course, you should be able to:

1. Understand how CSS works with HTML
2. Apply styles using selectors
3. Use classes and IDs properly
4. Work with colors, fonts, and text styling
5. Understand the CSS box model
6. Control layouts using:
  - Flexbox
  - Grid
7. Build responsive designs using media queries
8. Create animations and transitions
9. Write clean, maintainable CSS

**Course Goal**

The main objective is to enable learners to design visually appealing, responsive, and professional web pages.  

## Uses of CSS

CSS is widely used in:

1. Website Design

Controls the look and feel of websites.

2. Responsive Web Development

Adapts layouts for:

Mobile devices

Tablets

Desktop screens

3. Web Applications

Used with modern frameworks such as:

React

Angular

Vue

4. UI/UX Design

Improves user experience through spacing, alignment, and visual hierarchy.

5. Animations and Effects

Used to create:

Hover effects

Transitions

Keyframe animations

6. Theming and Customization

Allows global styling for large applications.
