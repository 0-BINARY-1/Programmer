# Introduction to HTML

HTML (HyperText Markup Language) is the standard markup language used to create and structure content on the web.  
HTML defines the structure of web pages using elements (tags) such as:  
```HTML
<h1>Heading</h1>
<p>This is a paragraph.</p>
<a href="https://example.com">Link</a>
```  

**It is not a programming language — it is a markup language used to organize content like:**

1. Headings
2. Paragraphs
3. Images
4. Links
5. Tables
6. Forms
7. Multimedia

**HTML works together with:**

1. CSS (for styling)
2. JavaScript (for interactivity)

3. Objectives of Learning HTML

**After completing this HTML course, you should be able to:**

1. Understand how web pages are structured
2. Create a complete HTML document
3. Use common HTML elements correctly respective to their function
4. Build forms and collect user input
5. Embed images, videos, and links in the HTML document.
6. Understand semantic HTML
7. Create basic responsive layouts
8. Prepare a strong foundation for CSS and JavaScript

## Course Goal

The main objective is to enable learners to build static web pages independently and understand how browsers interpret HTML documents.

### Uses of HTML

HTML is widely used in the following fields:

**Website Development**
Every website on the internet uses HTML as its base structure and shape.

**Web Applications**
Used in front-end development with frameworks like:

1. React
2. Angular
3. Vue, etc.

**Email Templates**
HTML is used to design structured email layouts.

**Documentation Pages**
Technical documentation, README files, and help systems use HTML structure.

**Content Management Systems (CMS)**
Platforms like WordPress rely heavily on HTML.

**Mobile App Development**
Hybrid apps use HTML with frameworks like Ionic or Cordova.
