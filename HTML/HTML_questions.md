# HTML Questions for practice

1. Design a page having suitable background color and text color with title “My First Web Page” using all the attributes of the Font tag (size, color and family).
2. Create a HTML document giving details of your NAME, ADDRESS AND EMAIL aligned in proper order using alignment attributes (left, right and center) of Paragraph tag.
3. Write HTML code to design a page containing a couple of paragraph using formatting tags (bold, italic and underline) by giving suitable heading tag of color red.
4. Write HTML code to demonstrate the use of pre-tag in a letter format.
5. Write HTML code to create a Web Page that contains an Image at its center and display moving message (“Hello, I am moving text.”) in red color.
6. Write a HTML code to embed Audio and Video into your HTML web page.
7. Create a web page, showing cafe name using H1 tag and an ordered list of all the food items available at cafe.
8. Create a web page, showing an unordered list of names of all the SAARC countries.
9. Create an HTML document containing a nested list showing chapter one content page of Computer Science Book of Grade XI.
10. Create a webpage with HTML describing your department using paragraphs and list tags.
11. Create web Pages using Anchor tag with its attributes for external links.
12. Demonstrate how internal hyperlink can be created with in a webpage.
13. Create a web page for a registration form using textbox, radio button, check box, password box, file browser, text area and submit button.
14. Create a web page to demonstrate select tag in HTML.
15. Create the given table in HTML with different font colors.
